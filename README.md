# job_search_course_work_2

## Описание:

job_search_course_work_2 - это программа, которая будет получать информацию о вакансиях с платформы hh.ru в России и
сохранять ее в базу данных.

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/RomanBatyuk/job_search_course_work_2
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

1. Откройте проект в PyCharm.
2. Теперь вы можете поучавствовать в учебном процессе ;)

## Функционал:

В корне проекта модуль main, запускает работу программы.

В директории src:

* iteraction_with_api - модуль для взаимодействия с API.
* iteraction_with_file - модуль для взаимодействия с таблицами.
* iteraction_with_vacancies - модуль взаимодействия с вакансиями.
